# 01. 디자인 시스템

> 키워드: **말랑 · 따뜻 · 또렷함**
> 파스텔은 "면(배경·칩·버튼)"에 쓰고, 글자는 항상 같은 색 계열의 **짙은 톤**으로 올려 대비를 확보한다.
> (파스텔 배경 위 흰 글씨 금지 → 대비 부족의 주원인)

## 1. 컬러 토큰

### 1.1 원칙

| 원칙 | 내용 |
| --- | --- |
| 파스텔 면 + 짙은 글자 | 모든 파스텔 배경에는 같은 계열의 `*-foreground`(짙은 톤)를 짝으로 정의한다. |

### 1.5 시각화 전용 상태 색

시각화는 "색 + 모양/라벨"을 함께 써서 색각 이상 사용자도 구분 가능하게 한다.

| 상태 | 색 | 추가 신호 |
| --- | --- | --- |
| 미방문(idle) | `--muted` 면 + `--border` 테두리 | — |
| 현재(current) | 토픽 색 면 + 2px `--primary-strong` 테두리 | 통통 튀는 scale 1.08 + 노디 발자국 아이콘 |

## 3. 형태 (Radius · Spacing · Shadow)

### Radius — "크게, 일관되게"

| 토큰 | 값 | 사용처 |
| --- | --- | --- |
| `--radius-xs` | 8px | 작은 배지, 코드 인라인 |
| `--radius-sm` | 12px | 입력창, 작은 버튼, 테스트 결과 행 |
| `--radius-md` | 16px | 기본 버튼, 탭, 칩(pill은 full) |
| `--radius-lg` | 20px | 카드 (기본 `--radius`) |
| `--radius-xl` | 28px | 패널, 모달, 워크스페이스 영역 |
| `--radius-2xl` | 36px | 히어로 카드, 마스코트 말풍선 |
| `--radius-full` | 9999px | 칩, 아바타, 진행 바 |

### Spacing
4px 그리드. 카드 내부 패딩 20–24px, 섹션 간격 32–40px, 페이지 좌우 여백 모바일 16px / 태블릿 24px / 데스크톱 32px.

### Shadow — 플럼/라벤더 틴트의 부드러운 그림자

```css
/* Light */
--shadow-soft:  0 1px 2px rgb(58 49 69 / 0.04), 0 4px 16px -4px rgb(58 49 69 / 0.08);
--shadow-float: 0 4px 8px -4px rgb(58 49 69 / 0.06), 0 16px 36px -10px rgb(106 79 209 / 0.18);
--shadow-pop:   0 3px 0 0 var(--primary-edge);            /* 눌리는 버튼의 "아랫입술" */
--shadow-inset: inset 0 1px 2px rgb(58 49 69 / 0.06);     /* 콘솔, 입력 */

/* Dark: 그림자 대신 "은은한 윗면 하이라이트"로 층을 표현 */
--shadow-soft:  0 1px 0 0 rgb(255 255 255 / 0.04) inset, 0 6px 20px -6px rgb(0 0 0 / 0.45);
--shadow-float: 0 1px 0 0 rgb(255 255 255 / 0.06) inset, 0 18px 40px -12px rgb(0 0 0 / 0.55);
--shadow-pop:   0 3px 0 0 var(--primary-edge);
--shadow-inset: inset 0 1px 3px rgb(0 0 0 / 0.35);
```

### 버튼 스타일 (Pop Button)
- 면: `--primary`, 글자: `--primary-foreground`, 아래 3px `--shadow-pop`
- hover: `translateY(-1px)`, 그림자 4px
- active(누름): `translateY(2px)`, 그림자 1px → "말랑하게 눌리는" 느낌
- 크기: sm 36px / md 44px(기본, 터치 최소 크기) / lg 52px

## 4. 모션

라이브러리: Framer Motion (현재 패키지명 `motion`, `import { motion } from "motion/react"`).

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `spring.bouncy` | `{ type: "spring", stiffness: 520, damping: 24 }` | 버튼, 칩, 스택 push/pop |
| `spring.gentle` | `{ type: "spring", stiffness: 260, damping: 28 }` | 패널, 카드 등장 |
| `spring.jelly` | `{ type: "spring", stiffness: 380, damping: 12, mass: 0.8 }` | 마스코트 점프, 정답 배지 |
| `duration.fast` | 0.15s | 호버, 색 전환 |
| `duration.base` | 0.25s | 탭 전환, 페이드 |
| `duration.slow` | 0.45s | 모달, 축하 연출 |

### 주요 마이크로 인터랙션

| 상황 | 연출 | 길이 |
| --- | --- | --- |
| 정답 | 노디 점프(y -16 → 0, jelly) + 토픽색 파티클 14개 방사형 버스트 + "+30 XP" 카운트업 | ~0.9s |
| 레벨 클리어 | 모달 + 노디 새싹에 꽃이 핌 + 파티클 | ~1.4s |
| 오답 | 틀린 테스트 카드 좌우 흔들기(±6px, 2회) + 노디 `oops` | 0.3s |
| 시간 초과 | 타이머 아이콘 째깍 흔들림 + 노디 `sleepy` | 0.4s |
| 힌트 열기 | 카드가 봉투처럼 위로 펼쳐짐(height auto + rotateX 살짝) | 0.3s |
| 스택 push/pop | 아이템이 위에서 떨어져 살짝 튀며 안착 / 위로 떠오르며 사라짐 (`layoutId` 유지) | 0.3s |
| 그래프 방문 | 노드가 1.08배 팡 → 1.0, 간선은 `pathLength` 0→1 로 그려짐 | 0.35s |

- **`prefers-reduced-motion`**: 파티클·점프 비활성화, 모든 spring을 0.15s 페이드로 대체. (전역 `MotionConfig reducedMotion="user"`)
- 과하지 않게: 한 화면에서 동시에 튀는 요소는 최대 2개.

### 불러오는 중 표시

- **페이지 이동**: 스피너 대신 **스켈레톤**(`Skeleton`, 실제 화면 모양을 닮은 회색 블록)으로 통일한다. 서버에서 데이터를 기다리는 경로(랭킹·마이페이지·관리자·AI 생성 문제)에만 `loading.tsx`를 둔다. 미리 만들어 두는 화면(대시보드·로드맵·토픽·문제)은 바로 넘어가고, 브라우저 진도를 읽는 순간에만 같은 스켈레톤을 보인다.
- **화면 맨 위 진행 막대**(`NavigationProgress`): 앱 안 링크 이동이 0.15초를 넘길 때만 나타나고 도착하면 사라진다. 빠른 이동에서는 보이지 않아 깜빡이지 않는다. 동작 줄이기 설정에서는 차오르지 않고 멈춘 막대로 보인다.
- **스피너(노디 `loading`)**: 버튼을 누르고 기다리는 동작(채점·AI 생성·저장)에만 쓴다.

## 6. 마스코트: 새싹 노드 "노디 (Nodi)"

### 6.1 컨셉
> "알고리즘 숲에 사는 **말랑한 노드 요정**. 그래프의 동그란 점(노드)이 살아 움직이게 된 존재."

| 요소 | 디자인 | 의미 |
| --- | --- | --- |
| 몸통 | 살짝 눌린 찹쌀떡 원형(가로:세로 = 1 : 0.9), 라벤더 크림 `#D9CCFF` | 그래프의 노드 |
| 머리 위 새싹 | 떡잎 2장, 줄기 끝이 살짝 말림 | 트리의 가지 / 성장 |
| 팔 | 몸통 양옆의 짧은 선 + 끝의 작은 동그라미 | 간선(edge)과 이웃 노드 — "손을 잡고 연결" |
| 얼굴 | 세로로 긴 점눈 2개 + 흰 하이라이트, 작은 U자 입, 복숭아 볼터치 `#FFC9DE` | 순한 인상 |
| 발 | 없음. 통통 튀어서 이동 | 가벼운 모션 |

기존 캐릭터와의 차별점: 동물·사물 모티프가 아닌 **"자료구조의 노드 + 새싹"** 이라는 도메인 고유 모티프이며, 팔이 "간선+노드" 형태라는 점이 시그니처.

### 6.2 성장 시스템
사용자의 누적 XP 레벨에 따라 노디의 새싹이 자란다. 토픽을 Lv5까지 마스터하면 새싹 끝에 **그 토픽 색의 꽃**이 하나씩 달린다(최대 7송이 → 꽃다발).

| 사용자 레벨 | 새싹 |
| --- | --- |
| 1–3 | 떡잎 2장 |
| 4–6 | 본잎 추가 (3장) |
| 7–9 | 꽃봉오리 |
| 10+ | 만개 + 마스터한 토픽 꽃 |

(사용자 레벨 공식은 [04-data-model.md](04-data-model.md) §2 참고. 커리큘럼 7토픽을 모두 마치면 대략 Lv10에 도달하도록 설계)

### 6.3 표정/모드 세트 (`MascotMood`)

| mood | 표정 | 모션 | 사용처 |
| --- | --- | --- | --- |
| `idle` | 기본 미소 | 4초마다 깜빡임, 숨쉬기(scaleY 1↔1.02) | 대시보드, 사이드바 |
| `happy` | 눈 ^^ 모양, 입 크게 | 점프 1회, 새싹 흔들 | 테스트 통과, 정답 |
| `cheer` | ^^ + 팔 위로 | 점프 2회 + 꽃 피움 | 레벨 클리어, 배지 획득 |
| `thinking` | 눈 한쪽 위, 입 일자 | 새싹이 "?" 모양으로 휨, 좌우 갸웃 | AI 코치 답변 대기, 힌트 |
| `oops` | 눈 ><, 땀방울 1개 | 살짝 뒤로 움찔 | 오답/런타임 에러 (항상 격려 문구와 함께) |
| `sleepy` | 눈 감김, zZ | 느린 호흡 | 빈 화면, 시간 초과 |
| `curious` | 눈 반짝(하이라이트 2개) | 앞으로 기울기 | 유형 인식 퀴즈, 새 토픽 해제 |
| `loading` | 기본 | 몸을 굴리며 데굴데굴 | 코드 실행, AI 문제 생성 중 |

### 6.4 말투 가이드 (AI 코치 · 피드백 공통)
- 부드러운 해요체, 한 번에 1–2문장. 이모지는 문장당 최대 1개.
- 오답에도 부정어로 시작하지 않는다. ✗ "틀렸어요." → ✓ "거의 다 왔어요! 2번 케이스만 다르게 나왔어요."
- 정답을 알려주는 대신 질문한다. "지금 방문 표시는 언제 하고 있나요? 두 번 세는 칸은 없을까요?"
- 예시
  - 정답: "해냈어요! 🌱 힌트 없이 풀었으니 새싹이 쑥 자랐어요."
  - 오답: "2개 케이스가 달랐어요. 대각선 칸도 연결로 세고 있진 않은지 볼까요?"
  - 시간 초과: "코드가 너무 오래 달리고 있어요. 같은 칸을 여러 번 방문하고 있진 않나요?"
  - 빈 화면: "아직 제출 기록이 없어요. 첫 문제를 같이 풀어볼까요?"

### 6.5 구현 방식 (Step 2)
- 순수 SVG React 컴포넌트 `<Nodi mood size growth flowers />`. 파츠(몸통/눈/입/볼/새싹/팔)를 분리해 mood별로 조합.
- 모션은 Framer Motion `variants`로 mood 전환. 외부 이미지·로티 파일 없음 → 다크모드 색 전환도 CSS 변수로 자동.
